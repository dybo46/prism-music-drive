# Prism Music Drive — 1.03

A browser-based, audio-reactive music visualizer. Load local MP3/WAV files or use the built-in synthesized demo. Audio and embedded artwork are processed on your device and are not uploaded.

## Development

Node.js 24 recommended. Run `npm ci`, then `npm run dev`.

## Validation and build

Run `npm test` and `npm run build`. GitHub Pages deployment is configured in `.github/workflows/pages.yml`.

This public repository is a publication snapshot of version 1.03. Private development notes, local music, and development history are not included. The local-only sample 2 is not distributed.

Third-party license information is in `THIRD_PARTY_NOTICES.md` and `public/third-party-notices.txt`.
